The loop you are in right now

  1. Ask in plain English. You just did this: “make a simple website to help me learn Cursor.”
  2. Watch the files change. Agent creates and edits index.html, styles.css, and script.js.
  3. Open the site. React. Like it? Keep going. Hate a color? Tell chat. That is the workflow.

Four modes, one job

Agent

Build and change files

Default mode for making things. Use it when you want code written, bugs fixed, or a feature added.

Ask

Read without editing

Questions only. “What does this file do?” Switch here when you want an explanation, not a rewrite.

Plan

Think before building

For bigger ideas. Agent maps the approach, you approve, then it builds. Cycle modes with Shift + Tab.

Inline

Tiny edits in place

Select some code, press Cmd + K, and say “make this heading smaller.” Fastest for one-spot changes.

Shortcuts worth muscle memory

Do this Mac
Open Agent chat Cmd + I
Inline edit selected code Cmd + K
Accept a Tab suggestion Tab
Add selected code to chat Cmd + Shift + L
Command palette Cmd + Shift + P

On Windows or Linux, use Ctrl instead of Cmd. Type @ in chat to point Agent at a specific file.
